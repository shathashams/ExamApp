Use Case Diagram - E-Test System

Actors:
1. Teacher
2. Student

Teacher Use Cases:
- Login
- Register
- View teacher dashboard
- View list of exams
- Manage exam
- Edit exam information
- Add new question
- Edit existing question
- View question details
- Logout

Student Use Cases:
- Login
- Register
- Open student portal
- Enter exam ID
- Start exam
- Answer questions
- Move to next question
- Go back to previous question
- Submit exam
- View score
- View results
- Logout

System:
- Authenticates users by role
- Loads exams from Mock API
- Displays pages based on user role

- Saves student results during the session
