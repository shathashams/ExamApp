E-Test System - Features Explanation

This project is a Full-Stack online exam system built with React 19, Bootstrap 5, a Node.js/Express backend server, and a PostgreSQL database (with a local JSON fallback option).

Users:
1. Teacher (Lecturer)
2. Student

Main Features:

1. Authentication & Security
- Stateless JWT-based authentication for secure session management.
- Secure password hashing using bcrypt on the server.
- Login and Register screens where users select their role (Teacher or Student).
- Middleware routes verification ensures students cannot access teacher resources and vice versa.

2. Teacher Pages & Exam Control
- Teacher Dashboard: View all exams created by the teacher.
- Create Exam: Author new exams with titles, allowed duration, extra time, permitted materials, and lecturer availability.
- Exam Management:
  - Add and edit questions.
  - Supports multiple question types: Multiple-Choice Questions (MCQs) and Open-Text Questions (auto-graded to 0, requiring manual grading override).
  - Modify existing question text, choices, and answers inline.
  - Publish exams: Toggle exam status from 'draft' to 'published' so students can access them.

3. Teacher Student Results & Grading
- Review Student Submissions: A side-by-side comparison of student responses against correct answers.
- Manual Grading & Feedback: Override calculated grades and write direct feedback for each student.
- Centralized Exam Management Tools:
  - Bulk Publish: Single-click button ("Publish All Marks") to release all results of an exam to students simultaneously.
  - Grade Factor Curves: Add factor adjustments (positive/negative points) globally to all submissions of a specific exam, with grades capped at 100%.
- Statistics & Visualization: Features a line-graph chart detailing score distributions and calculates exam grade averages.
- Real-Time Exam Monitoring: Live dashboard tracking active student test-taking sessions, elapsed times, and connectivity status (Online vs. Away/Offline via client-sent heartbeats).

4. Student Portal
- Enter Exam: Access any published exam by its unique ID.
- Take Exam: A step-by-step test-taking screen supporting navigation buttons (Next/Previous), progress bar indicators, MCQ radio selection buttons, and textarea boxes for open-text answers.
- Countdown Timer: A live countdown clock displays remaining time based on the exam duration. Changes color at 5 minutes (yellow) and 1 minute (red) warnings, and auto-submits the exam when time reaches zero.
- Submit Exam: Submits selected answers securely to the backend database.

5. Student Results & Review
- View Grades: Students see their finalized score and written comments once the teacher reviews and publishes the results.
- Review Answers: Click "View Details" to open a detailed modal displaying the correctness of their submitted answers, reference answers, and options.
- Feedback & Query Form: Ask questions or submit comments directly to the teacher.
- Publishing Alerts: Real-time alert notifications warn students immediately when the lecturer publishes their exam marks, allowing them to view details with a single click.

6. Navigation Menu
- Dynamic menu adjusts layout based on whether the logged-in user is a Teacher or a Student.
- Theme Switcher: Supports switching between Light and Dark mode layout styles.

7. Database Modes
- PostgreSQL Mode (docker_pg): Connects to a local PostgreSQL instance running inside a Docker container (default/recommended).
- JSON Mode (json): Fallback database helper storing records to db.json.
