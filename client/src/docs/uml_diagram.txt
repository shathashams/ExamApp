UML Diagram - Main Classes and Services

Class: ConfigService
Attributes:
- appName
- defaultExamTimeMinutes
- extraTimeMinutes
- teacherAvailableMinutes
Methods:
- getAppName()
- getDefaultExamTime()
- getExtraTime()
- getTeacherAvailableTime()
- isServerMode()
- getApiBaseUrl()

Purpose:
Stores general configuration values and API endpoint paths.


Class: LoggerService
Methods:
- info(message)
- warning(message)
- error(message)

Purpose:
Prints development messages to the browser console.


Class: StorageService
Methods:
- save(key, value)
- get(key)
- remove(key)
- clear()

Purpose:
Handles saving, reading, and clearing data in localStorage (e.g. user tokens).


Class: NotifyService
Methods:
- success(message)
- error(message)
- info(message)

Purpose:
Shows bootstrap notification/toast messages to the user.


Module: apiClient
Functions:
- getAuthHeaders()

Purpose:
Generates standard authorization headers containing stateless JWT tokens.


Module: authService
Functions:
- login(username, password, role)
- register(username, password, fullName, role)

Purpose:
Authenticates users against API or mockDb.


Module: examService
Functions:
- getAllExams()
- getExamById(id)
- createExam(exam)
- updateExam(updatedExam)

Purpose:
Fetches, creates, and updates exam configurations.


Module: scoreService
Functions:
- getScores(userId, userRole, username)
- saveScore(scoreData, userId, userRole, username)
- updateScore(id, scoreData)
- publishAllScores(examId)
- applyFactor(examId, factor)

Purpose:
Manages student results, grading, bulk publishing, and grade factors.


Module: feedbackService
Functions:
- getFeedbacks()
- submitFeedback(feedbackData)
- respondToFeedback(id, teacherResponse)
- acknowledgeFeedback(id)

Purpose:
Manages the message exchange / queries between students and teachers.


Module: monitorService
Functions:
- startLiveSession(examId, examTitle)
- sendLiveHeartbeat(examId)
- endLiveSession(examId)
- getLiveSessions()

Purpose:
Handles real-time active student sessions tracking.


Component: App
State:
- user
- authMode
- activePage
- theme
- studentResults
- feedbacks
- isExamActive
- publishAlerts
Main Functions:
- handleLogin()
- handleRegister()
- handleSaveResult()
- handleLogout()
- handleFeedbackSubmitted()
- handleRespondToFeedback()
- handleDismissFeedbackAlert()

Purpose:
Main entry point; coordinates state distribution and active view panels.


Component: StudentPortal
State:
- examId
- exam
- message
- currentQuestionIndex
- selectedAnswers
- isSubmitted
Main Functions:
- handleStartExam()
- handleExitExam()
- handleSelectAnswer()
- handleNextQuestion()
- handlePreviousQuestion()
- handleSubmitExam()

Purpose:
Renders the step-by-step exam assessment form for students.


Component: ExamManagement
State:
- localExam
- showAddQuestion
- showEditInfo
- editingQuestionId
- examInfo
- newQuestion
- editQuestion
Main Functions:
- startEditQuestion()
- saveQuestionChanges()
- handleAddQuestion()
- handleSaveExamInfo()

Purpose:
Renders the teacher's exam setup editor (question adding, type toggling, metadata updates).


Component: TeacherStudentResults
State:
- selectedExam
- exams
- selectedSubmission
- factorVal
- bulkSuccess
- bulkError
- processingBulk
Main Functions:
- handleTogglePublish()
- handlePublishAll()
- handleApplyFactor()

Purpose:
Displays student scores, averages, distribution charts, and bulk release tools.


Component: SubmissionReviewModal
State:
- manualGradeVal
- feedbackVal
- isPublishedVal
- savingGrading
Main Functions:
- handleSaveGrading()

Purpose:
Teacher modal for assessing student answers, adding custom notes, and overriding grades.


Component: StudentSubmissionReviewModal
Purpose:
Student modal to view the correctness of their submitted answers after grades are published.


Component: LiveMonitor
State:
- sessions
- loading
- error
- lastUpdated
Main Functions:
- fetchLiveSessions()
- getElapsedString()
- getConnectionStatus()

Purpose:
Teacher view details displaying live exam test takers, connection status (Online/Away), and start times.


Component: QuestionReviewCard
Props:
- question
- selectedAnswer
- questionIndex

Purpose:
Shared reusable card component that displays a single question's details, the student's answer choice, the correct answer, points, and correctness badges.
