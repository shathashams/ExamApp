UML Diagram - Main Classes and Services

Class: ConfigService
Attributes:
- appName
- defaultExamTimeMinutes
- extraTimeMinutes
- teacherAvailableMinutes

Methods:
- getAppName()
- getDefaultExamTime()
- getExtraTime()
- getTeacherAvailableTime()

Purpose:
Stores general configuration values for the application.


Class: LoggerService
Methods:
- info(message)
- warning(message)
- error(message)

Purpose:
Prints development messages to the browser console.


Class: StorageService
Methods:
- save(key, value)
- get(key)
- remove(key)
- clear()

Purpose:
Handles saving and reading data from localStorage.


Class: NotifyService
Methods:
- success(message)
- error(message)
- info(message)

Purpose:
Shows simple notification messages to the user.


Module: examService
Functions:
- getAllExams()
- getExamById(id)
- createExam(exam)

Purpose:
Simulates API calls and returns data from the mock database.
